# ORBIO

CRM web multi-segmento com design cinematográfico e experiência fluida de alto impacto.

Visual baseado no sistema **Relate** (canvas frio, azul `#145aff`, Inter, cards flutuantes). O produto é o próprio herói da interface.

## Stack

| Camada | Tecnologia |
|--------|-----------|
| Frontend | React + Vite |
| Estilização | Tailwind CSS v4 |
| Animações UI | Framer Motion |
| Animações avançadas | GSAP |
| Estado global | Zustand (persistido) |
| Navegação | React Router DOM |
| Ícones | Lucide React |
| Gráficos | Recharts |
| Kanban | dnd-kit |
| Backend / Auth | Supabase (opcional) |

## Como rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173).
